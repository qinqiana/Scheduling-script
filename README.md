# 入网审核排班

给省综调入网审核岗用的排班工具。班次为 **早 / 晚 / 休**，请假写 **假**。

## 怎么用

需要本机已安装 Node.js 18+。

双击 `启动排班.bat`，浏览器会打开 http://127.0.0.1:8787/ 。关掉黑色窗口即停止。

「生成 X 月」只排顶部所选年/月，出勤按国务院办公厅放假调休通知识别当月法定工作日（法定节假日和通告连休都不算，调休上班算；法定假日全员休，连休日按周末值班）。满自然周默认 5 上 2 休，和其他硬约束冲突时可以改成 4 上或 6 上，多出来的日期不再记加班。月末最后三天（法定假日除外）每组要多排人、最多休 1 人，且至少 2 个晚班在岗。

第一次会自动安装依赖并打包界面。之后只有改了前端才会重新打包，平时直接启动。数据在同目录 `data.db`。

对方电脑不能联网、也不能安装 Node.js 时：在本机双击 `制作绿色包.bat`，把 `release\入网审核排班.zip` 拷给对方。对方解压后双击「打开排班」即可。

各版本改动见 [CHANGELOG.md](CHANGELOG.md)。
