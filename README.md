# 入网审核排班

给省综调入网审核岗用的排班工具。班次为 **早 / 晚 / 休**，请假写 **假**，导出对齐现有《考勤表模板》。

## 能做什么

- 按自然月生成 20～30 人的班表（预置广州 / 佛山 / 中山清远现有名单）
- 硬约束：每组每天至少 1 早 1 晚；每人每周最多 5 天；请假不排
- 偏好：10～20 号少人，20 号以后多人、多晚班
- 软约束：晚班尽量均分（极差默认 ≤ 5）、第二周可少人、最后一周尽量多人
- 月历里点格子改班、锁定后「重排未锁定」
- 请假、节假日、冲突红字、缺口高亮、公平性统计
- 导出 Excel（整月考勤表 + 按人 + 统计）；备份 / 恢复就是拷贝 `data.db`

## 怎么跑

需要 Node.js 18+。

```bash
cd /d d:\入网审核排班
npm install
npm run dev
```

浏览器打开 http://127.0.0.1:5173 （开发）或 http://127.0.0.1:8787 （`npm start`，需先 `npm run build`）。

第一次启动会在项目根目录生成 `data.db`，并写入现有 14 人名单和 2026 年节假日。

## 导出模板

若本机存在下面任一文件，导出时会尽量往原模板里填「早 / 晚」：

- `d:\个人文件\项目\排班\考勤表模板.xlsx`
- `templates\考勤表模板.xlsx`

找不到模板，或名单对不上时，程序按同一张表结构自己生成：序号、姓名、支撑地市、1～31 日、本月出勤、早班、晚班。

## 数据

- SQLite 单文件：`data.db`
- 页面上可下载备份，人员页可上传恢复
- 人员 CSV：`姓名,组别,目标出勤`
